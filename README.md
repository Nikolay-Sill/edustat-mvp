# EduStat MVP

Прототип информационной системы аналитики успеваемости обучающихся **EduStat**.
Реализован по собственной проектной документации (требования, UML/IDEF0/DFD,
модель данных, OpenAPI 3.0) — см. папку `docs/`.

> Это **MVP-прототип**, а не промышленная система: реализованы требования
> с приоритетом M из ядра сценария «прогноз → группа риска → работа со случаем».
> Отклонения от целевой архитектуры перечислены ниже и в `docs/deviations.md`.

## Что умеет MVP

| Сценарий | Требования |
|---|---|
| Загрузка цифрового следа из «LMS» (мок-коннектор на датасете OULAD), журнал синхронизаций | FR-01, FR-02, FR-03 |
| Справочники групп, студентов, дисциплин, преподавателей и закреплений | FR-05 |
| Метрики студента, ML-прогноз задолженности, уровни риска, история прогнозов, 3 главных фактора | FR-06 – FR-10 |
| Группа риска с фильтрами; преподаватель видит только свои группы | FR-12, FR-24 |
| Случай риска: статусы, мера поддержки, передача в деканат, ложное срабатывание | FR-13 – FR-17 |
| Дашборд группы, поиск студента, фоновый отчёт в XLSX | FR-18, FR-21, FR-22 |

## Стек

| Слой | Целевая архитектура (документация) | MVP |
|---|---|---|
| Сервисы | 7 микросервисов, Java + Python | Модульный монолит на Python 3.12 + FastAPI |
| Связь сервисов | Apache Kafka | Вызовы между модулями + фоновые задачи |
| Данные | PostgreSQL 16, база на сервис, MinIO | PostgreSQL 16, одна база, схемы по модулям; файлы на диске |
| Безопасность | Keycloak, SSO (OAuth 2.0 / OIDC) | JWT-логин по паролю, роли из `academic.staff` |
| ML | CatBoost + MLflow | CatBoost + SHAP, модель в файле, версия в `analytics.model_version` |
| Клиент | React + TypeScript + ECharts | React + TypeScript + ECharts (или Streamlit как запасной вариант) |
| Инфраструктура | Kubernetes, GitLab CI/CD, Prometheus | Docker Compose, GitHub Actions (линтер + тесты) |

## Структура репозитория

```
edustat-mvp/
├── README.md
├── ROADMAP.md                  # план по этапам с привязкой к FR
├── docker-compose.yml          # PostgreSQL 16 + автоприменение миграций
├── db/
│   ├── migrations/
│   │   ├── V1__init_schema.sql     # 11 таблиц из Рисунка 6.1 (= edustat_schema.sql)
│   │   └── V2__mvp_extensions.sql  # факторы прогноза, уведомления, отчёты, пользователи
│   └── queries/edustat_queries.sql # проверочные запросы из раздела 6.3
├── backend/
│   ├── app/
│   │   ├── core/           # конфиг, подключение к БД, ошибки RFC 7807, пагинация
│   │   ├── auth/           # логин, JWT, проверка ролей и закреплений (FR-24)
│   │   ├── academic/       # справочники (FR-05), поиск студента (FR-22)
│   │   ├── integration/    # мок-коннектор LMS, sync_job, очистка данных (FR-01–03)
│   │   ├── analytics/      # метрики, прогноз, уровни риска, факторы (FR-06–10)
│   │   ├── risk_cases/     # группа риска и случаи риска (FR-12–17)
│   │   ├── notifications/  # уведомления в кабинете (FR-13)
│   │   └── reporting/      # дашборд группы, отчёт XLSX (FR-18, FR-21)
│   └── tests/acceptance/   # тесты по критериям приёмки US-01 – US-03
├── ml/
│   ├── notebooks/          # EDA и обучение модели на OULAD
│   └── models/             # обученные модели (в .gitignore)
├── data/raw/               # сюда кладётся OULAD (в .gitignore)
├── frontend/               # React-клиент
├── load-tests/             # сценарии k6
└── docs/
    ├── specs/              # проектная документация, edustat-openapi.yaml, диаграммы
    └── deviations.md       # журнал отклонений от спецификации
```

## Запуск (после этапа 1)

```bash
docker compose up -d db
# далее — инструкции по backend/frontend появятся по мере реализации
```

## Данные

Используется открытый датасет **OULAD** (Open University Learning Analytics Dataset,
лицензия CC BY 4.0). Персональные данные в нём обезличены; ФИО и e-mail для интерфейса
генерируются синтетически. Сопоставление таблиц — в `ROADMAP.md`, этап 2.
